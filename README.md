# Auto Kỷ Nguyên Hải Tặc (KYNHT Bot Tool)

Tool auto game **Kỷ Nguyên Hải Tặc** giúp người chơi tự động hóa các hoạt động như farm, làm nhiệm vụ và chiến đấu trong game.

## 🚀 Giới thiệu

**Auto Kỷ Nguyên Hải Tặc (KYNHT)** là script/tool hỗ trợ:

* Auto farm tài nguyên
* Auto làm nhiệm vụ
* Auto chiến đấu
* Giảm thao tác thủ công

Phù hợp cho người chơi muốn tiết kiệm thời gian khi chơi game **Kỷ Nguyên Hải Tặc**.
