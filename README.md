# Auto Kỷ Nguyên Hải Tặc bằng AutoHotkey v2

Tool **Auto Kỷ Nguyên Hải Tặc (KYNHT)** viết bằng **AutoHotkey v2** để hỗ trợ tự động hóa một số thao tác trong game như farm, nhiệm vụ và các tác vụ lặp lại.

> Repo này sử dụng **AutoHotkey v2 (AHK v2)** làm ngôn ngữ chính.

---

## Giới thiệu

**Auto Kỷ Nguyên Hải Tặc** là project bot/tool dành cho game **Kỷ Nguyên Hải Tặc**, được xây dựng bằng **AutoHotkey 2** nhằm giảm thao tác thủ công và hỗ trợ tự động hóa quy trình chơi game.

Project phù hợp cho người dùng đang tìm kiếm:

- auto Kỷ Nguyên Hải Tặc
- bot KYNHT
- AutoHotkey game bot
- tool auto game Kỷ Nguyên Hải Tặc
- script AutoHotkey v2 cho KYNHT

---

## Công nghệ sử dụng

- **AutoHotkey v2**
- PowerShell cho cài đặt / hỗ trợ setup
- Batch script cho khởi tạo nhanh
- Một số thành phần phụ trợ trong thư mục `tools`, `utils`, `gui`, `features`

---

## Tính năng chính

- Tự động hóa thao tác trong game
- Hỗ trợ các tác vụ lặp lại
- Có cấu trúc thư mục rõ ràng để mở rộng tính năng
